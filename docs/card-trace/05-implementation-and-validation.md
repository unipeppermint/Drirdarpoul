# 牌局档案 · 实现与验证记录

交付日期：2026-09-24。实现位于原 Drirdarpoul 工程，不是替代项目或静态页面。

## 运行

用 Xcode 打开 `Drirdarpoul.xcodeproj`，选择 `Drirdarpoul` Scheme 与 iPhone Simulator，运行即可。无第三方依赖，无联网、账户或付费前置条件。现有 Bundle ID `com.lovp.Drirdarpoul`、自动签名设置、版本号及 Target Debug/Release 的 iOS 14.0 均保留。修改的启动配置只负责从 Main Storyboard 切换到程序化 UIKit 根控制器，并设置中文应用名称。

首页提供继续推理、四章列表与进度。当前章节内可任选关卡；完成一章全部关卡后解锁下一章。40 关、三层提示、撤销、复盘与收藏全部免费。

## 完成范围

- 四个核心页面：档案首页、推理桌面、牌局复盘、档案收藏，以及章节列表、笔记编辑和设置。
- 40 个内置 JSON 关卡，四章 6/12/12/10，其中前 6 个教学关；已完成六牌闭环和前 8 关里程碑，继续交付到 40 关。
- UIKit 原生卡牌与时间线：点牌再点位置、系统本地拖放、牌位交换、从牌池替换、移回牌池、固定公开牌保护；最多 80 步撤销，不设重做入口。
- 可靠事实、可疑证词、玩家判断/笔记、作者答案、提示分别存储。局部检查采用三态；未知不判错，日常校验不逐格比对作者答案。
- 座次、赢家和下一轮领出者由同一个纯 Swift 规则引擎生成。顺序未知时按座次显示并明确标为待推断；已摆出的牌只作为玩家当前假设。
- 提示依次为关注方向、规则关系、明确一步；第三层有防误触确认，不自动代摆，不扣费。
- 成功与失败牌局都有逐手检查；支持播放/暂停、前后步、滑杆及点牌定位，后台暂停。错误复盘提供返回修正，合法复盘提供下一份档案。
- 收藏保留已还原故事、接受的真实牌面与推理笔记。重玩重置草稿，已完成收藏保留；不同内容修订不混用历史牌面解释当前关卡。
- Application Support 中版本化 JSON 自动存档、串行合并写入、原子主档/备份、笔记编辑合并保存、退出和后台刷新；损坏记录优先恢复备份，未来版本原文件只读保护。
- 完成记录写入及加载当前修订时均做规则语义校验；非法完成记录不能误解锁章节，可恢复为草稿继续推理。
- 暖白/深墨/酒红样式，已接入独立生成的版画插画、纸张纹理与本地宋体；应用图标及交互牌面仍由代码绘制。视觉升级及素材提示词见 [视觉素材 v2](06-visual-assets-v2.md)。
- Safe Area、纵向滚动、Dynamic Type（大字时卡牌两列）、VoiceOver 卡牌语义与移回操作、减少动态效果兼容、触感开关与加大字体设置。

## 实际界面验证

在专用 **iPhone 17 Pro / iOS 26.5** 与 **iPhone SE 第 3 代 / iOS 26.5** 模拟器运行了应用。

实际操作确认：

- 首关固定的三张公开牌和三个待归位牌准确，第二轮显示 B→C→A。
- 未填完提交显示“还有牌未归位”，证据不足保持待推断。
- 通过点选填出完整错误牌局，正确报告 C 仍有黑桃却未跟花色；错误牌局可逐手检查且未计入完成记录。
- 点选交换修正、撤销恢复；重启应用后恢复原摆牌、笔记和撤销能力。
- 正确完成首关，六手实际次序与 B/C 两轮赢家正确；首页变为 1/40 并引导第二关。
- 收藏能读到完成记录和笔记；再次推理时恢复初始空位，没有从完成记录自动填满答案。
- 三层提示可用，第三层明确确认；已读提示记录保存。
- 实际播放到第一手后退到后台，稍后返回仍为第 1/6 手且显示“播放”，没有自动继续；点最后一张牌可直接定位第六手。
- 小屏默认布局及加大文字模式下无横向溢出，卡牌变两列，底部按钮保持可达。
- 通过系统可访问性树核对了花色全名、轮次人物、固定/空位/选中态及只读复盘语义。

在上述专用主模拟器日志中未发现 `Unable to simultaneously satisfy constraints` 或未捕获异常记录。该日志检查不代表覆盖所有界面组合。
