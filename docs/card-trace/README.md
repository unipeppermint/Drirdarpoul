版本：1.0 · 日期：2026-09-24 · 状态：首版代码已实现，验证边界见交付记录

## 当前基线

- **最低支持 iOS 14.0，这是硬性要求。** 不采用此前建议的 iOS 15 最低版本。
- **当前版本全部内容免费，暂不引入付费。** 不接入内购、订阅、付费墙、付费提示或付费章节，不实现 StoreKit 业务。
- 采用 Swift + UIKit，iPhone 竖屏优先，核心玩法及存档离线运行。
- 原型中的章节锁仅表示按通关进度解锁；不代表购买条件。
- 首版内容目标为 40 关，含 6 个教学关；先交付 8 个可玩原型关进行验证。
- 保留现有 Bundle ID、签名团队及发布配置。业务实现已进入原工程，详见实现与验证记录。

用户最新要求优先于此前对话中的定价、买断、免费试用关卡和 StoreKit 2 方案；上述旧建议全部退出当前版本范围。
